# 代码注释中，TODO 不能因为多语言而导致出现成倍数量的标记

## 目的

检查多语言 TODO 的标记组织，避免同一待办被重复标记，并保持各语言说明逐句对应。

## 判断理由

TODO 标识的是待办任务。增加译文没有增加任务，因此不应增加任务标记。

公共标记独立成行，可以避免它依附于某一种语言的说明；各语言逐句对应，便于核对它们是否表达相同内容。

## 边界

- 本例说明按每句中文、英文的顺序排列。
- 不能把不同待办合并成一项来减少标记。
- 不能通过删除译文或删减已有说明来满足标记要求。

## 验收

- 每项待办恰好对应一个独立成行的 TODO 标记。X 项待办、K 种语言，仍只有 X 个标记。
- 每句说明均按规定的语言顺序提供等义版本，紧邻排列后再写下一句。

## 正例

```cpp
// TODO:
// 将 recordResult 接入真实 MySQL 占位账本；当前本函数通过注入接口交付结果，账本实现尚待接入。
// Connect recordResult to the MySQL reservation ledger; this function currently passes results through an injected interface, and ledger integration remains unfinished.
// 确认创建后，将新刊登关联到原 Action 的同一条占位，避免同一刊登重复计数。
// After creation is confirmed, link the new posting to the original Action's reservation to avoid counting the same posting twice.
// In Review 期间继续保留该占位，避免提前把该名额算作空闲。
// Retain that reservation during In Review so the slot is not counted as available prematurely.
```

## 反例

### 反例一：公共标记混入中文说明行

```cpp
// TODO: 将 recordResult 接入真实 MySQL 占位账本；当前本函数通过注入接口交付结果，账本实现尚待接入。
// Connect recordResult to the MySQL reservation ledger; this function currently passes results through an injected interface, and ledger integration remains unfinished.
// 确认创建后，将新刊登关联到原 Action 的同一条占位，避免同一刊登重复计数。
// After creation is confirmed, link the new posting to the original Action's reservation to avoid counting the same posting twice.
// In Review 期间继续保留该占位，避免提前把该名额算作空闲。
// Retain that reservation during In Review so the slot is not counted as available prematurely.
```

这里只有一个标记，但它与中文说明挤在同一行，公共标记没有独立于翻译内容。只删掉另一种语言的标记，仍未满足公共标记独立成行的要求。

### 反例二：同一待办随语言重复标记

```cpp
// TODO: 将 recordResult 接入真实 MySQL 占位账本；当前本函数通过注入接口交付结果，账本实现尚待接入。
// TODO: Connect recordResult to the MySQL reservation ledger; this function currently passes results through an injected interface, and ledger integration remains unfinished.
// 确认创建后，将新刊登关联到原 Action 的同一条占位，避免同一刊登重复计数。
// After creation is confirmed, link the new posting to the original Action's reservation to avoid counting the same posting twice.
// In Review 期间继续保留该占位，避免提前把该名额算作空闲。
// Retain that reservation during In Review so the slot is not counted as available prematurely.
```

这两行是同一任务的译文，不是两项任务；复制标记会让按标记检索和计数的统计得到两个待办。增加语言版本不能制造额外任务。
